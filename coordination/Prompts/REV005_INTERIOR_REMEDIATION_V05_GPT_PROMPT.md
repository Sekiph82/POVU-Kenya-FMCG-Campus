## Step 5 — Industrial lines

### Bottle Blow Molding
Make unmistakable:
preform feed -> oven/heating -> mould/clamp/blow cell -> bottle outfeed.

Use recognisable machine housings, guards, service space and line relationships.

### Liquid Filling / Packaging
Make unmistakable:
bottle infeed -> fill -> cap -> label/inspect -> secondary pack/case.

Use visible heads/nozzles, capper, label station, conveyors, guards and pack-out.

### Powder Handling / Packing
Make unmistakable:
powder feed/hopper -> handling/dosing -> pack/fill -> sealing/transfer.

Use process-specific geometry, not a generic conveyor plus box.

### Toothpaste Production
Make unmistakable:
vacuum mix -> hold/transfer -> tube feed -> tube fill -> seal/crimp -> code/inspect -> carton.

### Wet Wipes Production
Make unmistakable:
roll unwind -> web path -> wetting/impregnation -> fold/convert -> cut/stack -> pouch/feed film -> seal/discharge.

The visible web/roll/folding relationships must distinguish this line.
