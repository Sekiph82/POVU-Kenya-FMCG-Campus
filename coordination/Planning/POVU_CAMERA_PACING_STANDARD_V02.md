# POVU Camera and Pacing Standard V02

## Purpose

V02 is the implementation standard for the complete-tour storyboard. It preserves V01’s inspectable architectural-documentary pace while removing only redundant repeated context.

- Use slow, intentional camera motion.
- Establish, approach, inspect, hold, then depart where the model supports the sequence.
- Default hold: 2 seconds for a named destination; 3–5 seconds for a safety, water, control, PV or caveat relationship.
- Use one to three simultaneous labels; never use a dense label wall.
- Prefer 24–35 mm for campus/factory context, 35–50 mm for human-scale architecture, and 50–70 mm for evidence/detail inserts.
- Keep route continuity geographically motivated. A cut may bridge chapters only when the overlay restores orientation.

## Evidence-safe pacing

- HIGH: normal documentary motion with model and source agreement.
- MEDIUM: normal motion with neutral location label and no unsupported function claim.
- CAVEATED: slower hold with an explicit overlay or gap card; never imply missing geometry.
- Merged shots must preserve a visible change of target and at least one hold per originating V01 row.

## Required caveat language

- DOCUMENTED NOT MODELED — GATEHOUSE / SECURITY
- CIP / HYPOCHLORITE PROXY — DEDICATED SKID/VESSEL NOT IDENTIFIED IN REV004.1
- DOCUMENTED NOT MODELED — HEAVY MAINTENANCE / WORKSHOP
- UNPAIRED SOLAR-RELATED SUPPORTS — NOT COUNTED AS A FOURTH PV INSTALLATION
- 91 SKU PORTFOLIO — CAPABILITY/FAMILY COVERAGE, NOT 91 UNIQUE MODELED MESHES
