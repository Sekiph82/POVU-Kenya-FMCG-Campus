# POVU Kenya FMCG Campus

Central repository for the POVU Kenya integrated FMCG manufacturing campus project.

## Repository structure

- `3d/revisions/` — revision snapshots and metadata
- `3d/qa/` — QA render references and checks
- `3d/video/` — video route plans and rendered-video metadata
- `docs/` — project documentation and decision logs
- `presentation/` — PowerPoint deliverables and presentation notes
- `source/` — source/reference manifests

## Backup rule

Every successful and verified 3D revision should be archived with:
1. GLB snapshot
2. BLEND archive when available
3. QA render
4. Revision log / manifest
